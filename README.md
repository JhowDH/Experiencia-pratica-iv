# Experiencia Pratica IV - Desenvolvimento Front-end
# Instituto Novo Horizonte

Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento Front-end. O Instituto Novo Horizonte é uma organização fictícia criada para apresentar uma página institucional de uma ONG.

## Objetivo

Desenvolver um site simples, responsivo e acessível, utilizando tecnologias fundamentais do desenvolvimento web.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Apresentação institucional.
- Seção sobre a organização.
- Apresentação de projetos sociais.
- Formulário demonstrativo para voluntários.
- Informações de contato.
- Menu adaptado para dispositivos móveis.

## Acessibilidade

O projeto contempla recursos voltados à acessibilidade:

- Definição do idioma da página com `lang="pt-BR"`.
- Estrutura semântica com elementos HTML5.
- Link para pular diretamente ao conteúdo principal.
- Destaque visual para navegação por teclado.
- Campos de formulário identificados por rótulos.
- Indicação de campos obrigatórios.
- Mensagens dinâmicas com `aria-live`.
- Uso de `aria-expanded` e `aria-controls` no menu.
- Respeito à preferência por redução de movimento.

Esses recursos foram implementados como medidas de acessibilidade, mas a conformidade integral com as diretrizes WCAG 2.1 nível AA depende de validação adicional.

## Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/JhowDH/Experiencia-pratica-iv.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Experiencia-pratica-iv
   ```

3. Abra o arquivo `index.html` no navegador.

   Opcionalmente, utilize a extensão Live Server no Visual Studio Code.

Não é necessário instalar dependências ou configurar um servidor para visualizar a página.

## Observação sobre o formulário

O formulário é demonstrativo e realiza validações no navegador. Ele não envia nem armazena dados em um servidor.
